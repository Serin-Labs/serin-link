# Documentation

For a project introduction and repository map, see the [README](../README.md).

## Users

- [User manual](https://serin-labs.com/link/manual.html): quick start, pairing,
  controls, sensors, settings, updates, and resets.
- [Building and flashing](FLASHING.md): prebuilt images, browser and USB
  installation, source builds, and update feeds.
- [Hardware guide](HARDWARE.md): supported display modules, carrier sensors,
  required parts, and hardware design scope.
- [Build guide](https://serin-labs.com/link/build-guide.html): kit contents,
  assembly, stand printing, and firmware installation.
- [Technical reference](https://serin-labs.com/link/technical-reference.html):
  display differences, controller Wi-Fi limits, and home-app and ESPHome setup.
- [Troubleshooting](TROUBLESHOOTING.md): build and runtime problems, USB
  diagnostics, and console commands.
